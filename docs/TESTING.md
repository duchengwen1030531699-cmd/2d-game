## 3. 验收标准（来自 GDD）

1. **操作完整性**: 鼠标和触控均可完成采购、排产、查看库存、调整未开始队列、领取与交付订单、购买升级。
2. **闭环验证**: 玩家能从零原料完成"采购 → 面糊 → 早餐成品 → 自动售卖 → 获得金币"的完整闭环。
3. **边界反馈**: 原料不足、成品库存满、订单超时、订单预留和 2 小时离线结算上限都有清晰结果，且不会造成流程卡死。
4. **升级可感知**: 三类升级均可购买，并能在生产、仓储、销售任一对应环节产生可观察的效率变化。
5. **软失败**: 所有经营失误均为软失败：降低收益或口碑，但不触发 Game Over 或强制重开。
