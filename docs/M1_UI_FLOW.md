# M1 主界面线框与操作流程

> 对应版本：M1 单店可玩原型<br>
> 设计目标：在 1280×720 横屏内同时保留街区经营演出与完整的触控 / 鼠标经营操作。

---

## 1. 主界面线框

界面采用温暖扁平插画风：奶油色面板、橙色主操作、草绿色供应商入口。日常状态底部抽屉收起；新手首次进入时高亮“采购”入口。

| 区域 | 展开抽屉时 | 抽屉收起时 | 内容 |
|------|---:|---:|------|
| 资源栏 | 0–56px | 0–56px | 金币、口碑、原料 / 中间品容量、成品容量。 |
| 订单任务条 | 56–96px | 56–96px | 订单解锁进度，或已接订单的目标、进度与倒计时。 |
| 横板街区 | 96–400px | 96–656px | 可左右浏览的供应商、早餐店、订单板与升级入口。 |
| 底部经营栏 | 400–456px | 656–720px | `采购`、`制作`、`订单`、`升级`四个入口。 |
| 经营抽屉内容 | 456–720px | 不显示 | 当前唯一打开的功能页。 |

- 展开抽屉总高度为 320px；功能页内容不足时不拉伸，内容超出时只在抽屉内部纵向滚动。
- 窄屏横屏下，抽屉内原本左右并列的内容改为上下堆叠；资源栏允许换行，订单任务条保留一行主目标与一行倒计时。
- 街区建筑与底栏入口始终映射到同一页：供应商→采购、早餐店→制作、订单板→订单、升级入口→升级。

## 2. 持久信息与状态

### 资源栏

- 金币、口碑、原料 / 中间品占用、成品占用在所有状态常驻显示。
- 容量为满时，对应容量文字改为警示色，但不弹出阻断式窗口。

### 订单任务条

| 订单状态 | 显示内容 | 主提示 |
|------|------|------|
| 未解锁 | 普通顾客购买进度，例如“再售出 2 份解锁订单”。 | 引导玩家制作和售卖。 |
| 待接取 | 订单目标、120 秒时限、60 金币与 3 口碑奖励。 | 订单页出现红点。 |
| 已接取 | 目标商品、已预留数量 / 目标数量、剩余时间。 | 玩家可切换至制作页安排队列。 |
| 待交付 | “订单已完成，可交付”。 | 订单页出现数字 1。 |
| 已超时 | “订单已超时，口碑 -1”。 | 顶部短提示，随后进入 90 秒刷新等待。 |

### 非持久化 UI 状态

`UiState` 仅保存当前界面表现，不写入自动存档：

- `active_drawer_page`：`none`、`purchase`、`craft`、`orders`、`upgrades`。
- `street_camera_x`：街区横向镜头偏移。
- `toast_queue`：依次展示的轻量提示。
- `tutorial_highlight`：首局高亮的入口；M1 初始值为 `purchase`。

## 3. 输入与导航规则

- 鼠标左键点击 / 单指轻触建筑或底栏入口，打开对应抽屉页；点击当前已打开的底栏入口或抽屉关闭按钮，收起抽屉。
- 在街区非交互区域按住拖拽或单指滑动可左右浏览；指针横移超过 12px 时认定为浏览操作，不触发建筑点击。
- 建筑、底栏按钮、抽屉按钮会阻止街区镜头拖拽；鼠标滚轮和抽屉内单指纵向滑动只滚动当前抽屉内容。
- 同一时刻只能打开一个抽屉页；切换入口直接替换当前页，不额外堆叠弹窗。

## 4. 经营页流程

### 采购页

1. 显示面粉、鸡蛋、葱花的单价、当前库存和容量。
2. 每种原料提供减号、数量输入、加号；数量不能低于 0，也不能超过剩余容量或玩家金币可购买的数量。
3. 页面底部实时显示采购数量、总价与预计库存占用。
4. 点击“确认采购”后扣除金币、原料入库、清空采购清单并保留采购页；失败时仅显示金币或容量不足的短提示。

### 制作页

1. 左侧显示面糊、鸡蛋饼、葱油饼三张配方卡，包含材料、制作时间、售价或中间品标记。
2. 右侧显示原料 / 中间品库存、成品库存和生产队列。
3. 点击“加入队列”时立即进行材料与容量预检；成功后预留材料并将任务放入队尾。
4. 队首生产中任务显示名称、进度与剩余时间，且不显示排序或取消操作。
5. 未开始任务显示上移、下移、取消；取消立即返还预留材料。队列只有一个任务时，上下移动按钮禁用。
6. 成品库存满导致待取时，队首显示“等待空位”，后续队列暂停；容量恢复后自动入库并继续生产。

### 订单页

1. 无订单时显示普通顾客累计售出进度与下一单生成条件。
2. 待接订单显示目标、时限、奖励和“接取订单”；接取后订单状态进入任务条，并开始 120 秒倒计时。
3. 已接订单显示预留数量、目标数量与倒计时；订单完成后将主按钮替换为“交付订单”。
4. 点击交付后增加 60 金币与 3 口碑，清空预留库存，并开始 90 秒的下一单刷新等待。
5. 订单超时后停止倒计时、扣除 1 口碑、清空订单预留规则，并显示短提示；不打开弹窗、不强制跳转页面。

### 升级页

1. 三张升级卡始终显示成本、效果和当前状态；生产速度卡显示“推荐”标识。
2. 金币不足时升级按钮仍可点击，点击后提示“金币不足，还差 N 金币”。
3. 成功购买后立即更新对应资源、制作时间或目录售价，卡片改为“已升级”且按钮禁用。
4. 所有升级在 M1 中限购一次，不提供二次确认弹窗。

## 5. 轻量反馈

| 事件 | 顶部短提示 | 底栏状态 |
|------|------|------|
| 采购、排产、取消、升级成功 | 显示结果 2 秒。 | 无额外标记。 |
| 原料不足、容量满、金币不足 | 显示失败原因 2 秒。 | 制作或升级入口可显示小红点。 |
| 成品完成、订单待接、订单待交付 | 显示可行动提示 2 秒。 | 制作或订单入口显示红点 / 数字。 |
| 订单超时 | 显示“订单已超时，口碑 -1”2 秒。 | 订单入口清除标记并显示刷新等待。 |

提示按照 `toast_queue` 顺序展示，不遮挡抽屉主操作，也不暂停生产、顾客购买或订单倒计时。

## 6. 验收标准

1. 1280×720 横屏下资源栏、任务条、街区和已展开抽屉可同时阅读；抽屉收起后街区高度恢复。
2. 建筑入口与对应底栏入口打开相同的功能页；滑动街区超过 12px 时不会误开建筑。
3. 鼠标与触控均可完成批量采购、排产、未开始队列排序 / 取消、接单、交付与升级。
4. 四种订单状态在订单页和任务条中均有对应显示，且待交付状态停止倒计时。
5. 所有经济失败以短提示反馈，不产生强制弹窗、Game Over 或中断经营循环。
