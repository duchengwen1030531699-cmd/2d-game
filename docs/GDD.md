## 1. 游戏愿景

《晨光街》是一款**温馨现实题材的横板放置类模拟经营游戏**。玩家从一家小小的早餐店起步，采购原料、安排备餐、服务顾客并完成特殊订单，逐步提升店铺等级与口碑，最终扩张为一条繁荣的商业街。

横向可滚动街区呈现店铺、顾客与生产过程，提供舒适的“看着生意变好”的反馈；实际经营由清晰的面板操作完成，不包含角色移动、战斗或建筑摆放策略。

**核心体验关键词**：温馨、清晰、轻度策略、实时经营、持续成长。

---

## 2. 核心玩法循环

```
手动采购原料 → 安排生产队列 → 成品入库 / 上架 → 顾客自动购买
      ↑                                              ↓
扩张街区 ← 升级设施 ← 获得金币、口碑与订单奖励 ← 交付特殊订单
```

玩家通过原料成本、库存容量、生产时间与订单优先级做出取舍；普通顾客提供稳定收入，特殊订单提供额外奖励和短期目标。首版不提供玩家调价、动态市场或硬性失败条件。

### 长期目标

- 提升当前店铺等级，解锁效率更高的设施与配方。
- 累积金币与口碑，解锁新的街区区域和店铺类型。
- 将单店发展为具有多种经营主题的商业街。

## 3. 基础操作与界面

游戏同时支持触控与鼠标，所有核心操作都可通过点击 / 触碰完成。横板街区可左右浏览，但不要求控制角色。

| 入口 | 玩家操作 | 结果 |
|------|----------|------|
| 店铺 / 工坊 | 点击场景中的店铺 | 打开库存、配方和生产队列面板 |
| 供应商 | 点击供应商入口 | 购买基础原料并扣除金币 |
| 配方面板 | 点击配方 | 预留原料并将任务加入生产队列 |
| 生产队列 | 取消未开始任务、调整未开始任务顺序 | 返还原料或改变后续排产优先级 |
| 订单板 | 查看、追踪、交付特殊订单 | 获得订单奖励或查看超时结果 |
| 升级入口 | 购买设施升级 | 改变生产、库存或销售效率 |

### 时间与离线规则

- 游戏内经营固定以 **1 倍实时** 推进，不提供暂停、加速或营业日结算。
- 游戏切至后台或关闭后，生产与自动售卖最多继续结算 **2 小时**。
- 超出 2 小时的离线时长不再产生生产或销售进度；玩家回归后从当前状态继续经营。

## 4. 经营系统

### 4.1 资源与库存

| 概念 | 定义 |
|------|------|
| 原料 | 从供应商手动购买的基础材料，用于生产。 |
| 成品 | 由配方产出、可供顾客购买或交付订单的商品。 |
| 库存 | 存放原料与成品的容量系统；容量受仓储升级影响。 |
| 金币 | 采购、升级的通用货币，主要来自顾客消费和订单奖励。 |
| 口碑 | 反映经营表现的成长指标，用于后续街区与店铺解锁。 |

基础原料需要玩家主动采购，避免经营完全自动化。原型不引入采集、农场或上游自产原料。

### 4.2 两级配方与生产队列

首店为早餐店，原型采用两级配方：

1. 基础原料加工为中间品 **面糊**。
2. 使用面糊加工为可售卖的 **鸡蛋饼** 或 **葱油饼**。

配方价格固定，生产以队列串行执行。后续版本可增加并行设备与更多配方，但首版只验证单店、两级加工和排产取舍。

| 队列状态 | 规则 |
|------|------|
| 加入队列 | 立即预留所需原料；库存不足时禁止加入并明确提示缺少内容。 |
| 未开始 | 可取消并返还全部预留原料；可调整与其他未开始任务的顺序。 |
| 生产中 | 不可取消，任务按固定实时推进。 |
| 完成 | 成品进入库存；成品库存满时停留为待取状态，空出容量后自动入库。 |

### 4.3 普通顾客与特殊订单

**普通顾客**会在街区中自动到店，并在存在可售成品时按固定售价购买。玩家不直接服务顾客，也不调整商品价格。

**特殊订单**是带有目标商品与时限的额外经营任务。订单需要的成品会被预留，普通顾客不能购买预留库存。按时交付可获得额外金币与口碑；订单超时只损失该订单奖励并降低少量口碑，游戏不会结束。

### 4.4 设施升级

首版仅包含三类升级，均消耗金币：

| 升级类别 | 可见效果 |
|------|------|
| 生产速度 | 缩短每个生产任务的完成时间。 |
| 库存容量 | 提高原料与成品的可存储上限，减少队列堵塞。 |
| 柜台销售效率 | 提升普通顾客购买频率或单次售卖效率。 |

## 5. 首个可玩原型（M1）

M1 只验证“一家早餐店能否形成有趣的持续经营闭环”。原型包含：

具体的初始数值、配方、订单与升级成本见 [M1 数值与经济规格](M1_BALANCE.md)。

主界面线框、页面内容与完整操作流程见 [M1 主界面线框与操作流程](M1_UI_FLOW.md)。

- 一段可横向浏览、以展示为目的的温馨街区。
- 一家早餐店、一个供应商入口、一个订单板和一个升级入口。
- 原料采购、库存显示、面糊 / 鸡蛋饼 / 葱油饼三种配方及串行生产队列。
- 普通顾客自动购买、特殊订单预留与交付、金币和口碑反馈。
- 生产速度、库存容量、柜台销售效率三项可购买升级。
- 有限离线结算、库存不足、库存满和订单超时的明确反馈。
- 用于离线结算的单档自动保存，不提供手动存档管理。

### 不在 M1 范围内

- 角色移动、跳跃、战斗、敌人、关卡和生命值。
- 建筑自由摆放、顾客路径规划、员工雇佣或多店并行经营。
- 动态市场价格、手动定价、硬失败、付费系统、多存档与云同步。

---

## 6. 原型验收标准

1. 鼠标和触控均可完成采购、排产、查看库存、调整未开始队列、领取与交付订单、购买升级。
2. 玩家能从零原料完成“采购 → 面糊 → 早餐成品 → 自动售卖 → 获得金币”的完整闭环。
3. 原料不足、成品库存满、订单超时、订单预留和 2 小时离线结算上限都有清晰结果，且不会造成流程卡死。
4. 三类升级均可购买，并能在生产、仓储、销售任一对应环节产生可观察的效率变化。
5. 所有经营失误均为软失败：降低收益或口碑，但不触发 Game Over 或强制重开。
