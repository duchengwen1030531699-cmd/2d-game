# 2D 冒险（暂定名）— 游戏设计文档 GDD v0.1

> 项目代号：2d-game
> 引擎：Godot 4.7.1（GL Compatibility 渲染，移动端优先）
> 平台：Android / iOS（横屏）→ 后续可发布 Web/桌面
> 文档状态：概念提案，等待确认

---

## 1. 游戏愿景（Elevator Pitch）

一款**卡通风格的横板 2D 冒险手游**：玩家操控小骑士穿越草原、洞穴与城堡，
通过跑跳、冲刺与轻量战斗收集金币、击败敌人，最终击败每关的守护者通关。

**核心体验关键词**：爽快的移动手感、清晰可爱的画面、3~5 分钟一局的碎片化关卡。

---

## 2. 核心玩法循环（Core Loop）

```
进入关卡 → 跑跳/冲刺/攻击 → 收集金币与宝箱 → 遭遇敌人与机关
        → 成功到达终点（或失败回到检查点）→ 结算评分 → 解锁下一关
```

- 单局时长：3~5 分钟
- 失败状态：生命归零 → 回到当前检查点，金币保留 50%
- 进度：关卡制 + 世界地图（3 个世界，每个 5 关 + 1 BOSS 关）

---

## 3. 玩家能力与操作（Player Verbs）

| 操作 | 说明 | 解锁方式 |
|------|------|----------|
| 移动 | 左/右跑动 | 默认 |
| 跳跃 | 可变高度跳跃（长按跳更高） | 默认 |
| 冲刺 | 空中/地面短距离冲刺，可穿越敌人 | 世界 1 第 2 关解锁 |
| 二段跳 | 空中再跳一次 | 世界 2 解锁 |
| 攻击 | 近战挥剑，可打断敌人 | 默认 |
| 滑铲 | 快速下蹲滑行，通过低矮通道 | 世界 3 解锁 |

**手感标准（Game Feel）**：
- 移动加速度约 1200 px/s²，最大速度 320 px/s，摩擦 1400 px/s²
- 跳跃高度约 96 px，短按跳高度减半（跳跃取消）
- 土狼时间（coyote time）80ms + 跳跃缓冲（jump buffer）120ms
- 屏幕震动与粒子反馈：落地尘土、冲刺拖尾、攻击命中停顿

---

## 4. 关卡设计（Level Design）

- **世界 1 翡翠草原**：教学关，学习移动/跳跃/攻击；敌人为慢速史莱姆
- **世界 2 幽暗洞穴**：平台跳跃强化，引入尖刺与移动平台；敌人为蝙蝠
- **世界 3 王国城堡**：机关与节奏关，引入炮台与 BOSS 战

每关布局原则：**教学 → 熟悉 → 组合 → 挑战**，每关至少包含 1 个宝箱（3 金币）与 3 个可收集金币。

---

## 5. 美术与音频方向（Art & Audio）

- **风格**：卡通圆润风，高饱和色彩，主色绿/蓝/橙
- **角色**：小骑士（32×32 像素，2~4 帧行走 + 跳跃 + 攻击动画）
- **背景**：视差滚动（2~3 层）
- **音频**：轻快 MIDI 风格 BGM；跳跃/攻击/金币/受击音效
- **占位阶段**：先用纯色几何体（ColorRect/CollisionShape）搭建可玩原型，
  正式美术资源后续用 ImageGen 生成或引入开源素材

## 6. 技术架构（Godot 4.7.1）

```
scenes/
├── menus/        # 主菜单、关卡选择、设置
├── levels/       # 关卡场景（world1_01.tscn ...）
├── player/       # 玩家角色（Player.tscn）
├── enemies/      # 敌人（Slime, Bat, Turret...）
├── ui/           # HUD、虚拟摇杆、结算界面
└── objects/      # 金币、宝箱、检查点、机关
scripts/
├── autoload/     # GameManager / AudioManager / SaveManager
└── (按场景同名组织)
assets/
├── sprites/      # 角色/敌人/物体/UI
├── audio/        # BGM / SFX
└── fonts/        # 字体
docs/GDD.md       # 本文档
```

**Autoload 规划**：
- `GameManager`：当前关卡、金币、生命、评分
- `AudioManager`：BGM 切换、SFX 播放、音量持久化
- `SaveManager`：进度保存（user://save.json）

**渲染**：GL Compatibility（2D 足够且兼容性最好）
**分辨率**：1280×720 基准，`canvas_items` 拉伸 + `expand` 适配不同屏幕
**方向**：横屏（Sensor Landscape），移动端触控 UI 叠加
