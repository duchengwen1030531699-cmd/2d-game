# 2d-game

> 《晨光街》（暂定名）——横板放置类模拟经营游戏。

玩家经营一家温馨的早餐店：手动采购原料、安排生产队列、完成顾客订单，
再以金币与口碑扩张为一条热闹的商业街。横向街区用于展示店铺、顾客与生产过程；
核心管理通过触控或鼠标面板完成。

基于 **Godot 4.7.1**（GL Compatibility 渲染），面向横屏 Android / iOS，后续可适配桌面与 Web。

## 快速开始

1. 用 Godot 4.7.1 打开本目录（导入 `project.godot`）。
2. 按 F5 运行，进入主菜单。
3. 当前场景仍为项目骨架；M1 将替换为单店经营原型。

## 原型核心操作

- 点击 / 触碰店铺：打开经营面板
- 点击 / 触碰供应商：购买原料
- 点击 / 触碰配方：加入生产队列、取消未开始任务或调整队列顺序
- 点击 / 触碰订单板：查看、追踪与交付特殊订单
- 点击 / 触碰升级入口：提升生产速度、库存容量或柜台销售效率
