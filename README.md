# 2d-game

一个基于 **Godot 4.7** 的 2D 游戏项目。

## 环境要求

- Godot 4.7.1（标准版，支持 GL Compatibility 渲染）

## 快速开始

1. 用 Godot 打开本目录（导入 `project.godot`）。
2. 按 F5 运行，主场景为 `scenes/main.tscn`。

## 目录结构

```
2d-game/
├── project.godot      # Godot 项目配置
├── icon.svg           # 项目图标
├── scenes/            # 场景文件
├── scripts/           # GDScript 脚本
└── assets/            # 美术、音频等资源
```
